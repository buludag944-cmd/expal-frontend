# Use your own logo in EXPal

## Quick steps

1. Prepare **one square PNG** (your logo on a background you like).
   - **Best size:** 1024×1024
   - **Minimum:** 512×512
   - Must be **square** (same width and height).

2. Save it as:

   ```
   frontend/resources/icon.png
   ```

   (Replace the existing file.)

3. Apply everywhere:

   ```bash
   cd frontend
   npm run logo:apply:cap
   ```

   This updates:
   - Website header, login screen, browser tab (`public/expal-logo.png`, `logo192.png`, `logo512.png`)
   - **Android / iOS** app icons and splash (`cap:assets`)

4. Redeploy **Netlify** (drag `build/` or git push).

5. Rebuild the **native app** if you changed store icons:

   ```bash
   npm run cap:sync
   ```

---

## What each file does

| File | Purpose |
|------|---------|
| `resources/icon.png` | **Your master logo** — you only edit this |
| `public/expal-logo.png` | Shown in the app header & login (auto-generated) |
| `public/logo192.png` / `logo512.png` | PWA / Add to Home Screen |
| Android `mipmap-*` / iOS icons | Generated by `logo:apply:cap` |

---

## Tips

- **Wordmark logos:** use a dark slate background (`#0f172a`) to match the app theme (see `assets.config.json`).
- **Not square?** Crop in Preview, Canva, or Figma before saving as `icon.png`.
- **Only changing the website** (not store icons): `npm run logo:apply` (without `:cap`).

---

## Already have `expal-app-icon-512.png`?

Copy and scale:

```bash
cp /path/to/your-logo.png frontend/resources/icon.png
# If not 1024×1024:
sips -z 1024 1024 frontend/resources/icon.png
cd frontend && npm run logo:apply:cap
```
